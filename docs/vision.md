# Бачення проєкту «Система управління студентами»

## Мета

Спростити та систематизувати облік студентів, академічних груп, дисциплін та оцінок у навчальному закладі. Система забезпечує викладачам зручний інструмент для ведення успішності, а студентам — швидкий та прозорий доступ до власних результатів навчання.

## Користувачі

| Роль | Потреби |
| --- | --- |
| Викладач | Перегляд списку студентів та їхніх оцінок за групами, додавання й редагування записів про студентів, виставлення та оновлення оцінок, пошук за прізвищем, експорт результатів у CSV |
| Студент | Авторизація в системі та перегляд власних оцінок з навчальних дисциплін |
| Розробник клієнта | Доступ до структурованого REST API у форматі JSON для інтеграції з односторінковим клієнтом (Vue.js) |
